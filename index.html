Política de Privacidad

Última actualización: Julio 2026

CFDI Verifier es una aplicación desarrollada por CIIS para verificar la autenticidad de comprobantes fiscales digitales (CFDI) utilizando los servicios públicos del Servicio de Administración Tributaria (SAT).

Información recopilada

La aplicación no solicita registro de usuarios ni credenciales de acceso.

No recopilamos información personal identificable.

Uso de la cámara

La cámara únicamente se utiliza para leer el código QR contenido en los comprobantes CFDI. Las imágenes capturadas no son almacenadas ni enviadas a servidores de CIIS.

Archivos XML

El usuario puede seleccionar archivos XML almacenados en su dispositivo para realizar consultas. Los archivos son procesados únicamente para obtener la información necesaria para la verificación del comprobante.

Consulta al SAT

Las consultas se realizan directamente desde el dispositivo del usuario hacia los servicios públicos del SAT. CIIS no recibe, almacena ni procesa la información consultada en servidores propios.

Almacenamiento local

La aplicación conserva únicamente la última consulta realizada dentro del dispositivo para mejorar la experiencia del usuario. Esta información permanece almacenada localmente y no es compartida con terceros.

Publicidad

La aplicación no muestra publicidad.

Compartición de información

No vendemos, compartimos ni transferimos información del usuario a terceros.

Seguridad

La información permanece en el dispositivo del usuario y las consultas se realizan mediante conexiones seguras cuando el servicio del SAT lo permite.

Aplicación independiente

CFDI Verifier es una herramienta desarrollada por CIIS. No está afiliada, respaldada ni representa al Servicio de Administración Tributaria (SAT).
